# Goal
The SQL produced by `generate_search_sql` for a legal DFS expression
must honour F0001 + F0002 on every value literal — including those
wrapped in `unaccent_lower(…)` for text tags.

# Gap
`build_tag_value_filter` in
[`document-server/src/engine/generator.rs`](../../document-server/src/engine/generator.rs)
still bypasses `to_sql_literal`:

```rust
let value = &filter_condition.value.to_string();
format!("unaccent_lower((tv.value_string)::text) {0} unaccent_lower('{1}')", sql_op, value)
```

A `'` in the value breaks the query; `ValuePattern`'s wildcard-vs-literal
`%` distinction collapses. F0003 routes the emission through
`to_sql_literal`.

# Inputs
- `FilterExpressionAST` — any composition of `Condition` / `Logical`.
- `TagDefinition` per attribute (`Text`, `Int`, `Double`, `Bool`, …).

# Output
A single SQL `String`:

```sql
SELECT … FROM cs_<customer>.item i
  LEFT OUTER JOIN (
    SELECT tv.item_id, tv.<value_col> AS value
    FROM cs_<customer>.tag_definition td
    JOIN cs_<customer>.tag_value tv
      ON tv.tag_id = td.id
     AND td."name" = '<tag>'
     AND <fragment>            -- ← F0003 lives here
  ) ot_<tag>_<i> ON ot_<tag>_<i>.item_id = i.id
  …
WHERE …
```

`<fragment>` is built per Rule 2 / Rule 3 below.

# Rules

1. **Single source of truth.** Every value literal goes through
   `to_sql_literal(value, operator)` from `filter/mod.rs`. No
   `Display` / `to_string` shortcut.

2. **Text wrapper (`TagType::Text`).** Wrap the body, keep the
   `ESCAPE` suffix outside:

   | `to_sql_literal` returns | emitted fragment                            |
   |--------------------------|---------------------------------------------|
   | `'body'`                 | `unaccent_lower('body')`                    |
   | `'body' ESCAPE '\'`      | `unaccent_lower('body') ESCAPE '\'`         |

   Final shape:

   ```text
   unaccent_lower((tv.value_string)::text) <op> <wrapped_literal>
   ```

3. **Non-text wrappers.** `Int` / `Double` / `Bool` unchanged —
   `to_sql_literal` already emits unquoted atoms (`18`, `TRUE`, …).

4. **Template integrity.** `QUERY_FILTER_TEMPLATE` and the
   count-query template consume `<fragment>` verbatim — no further
   escaping at the template level.

# Errors
None. Pure emission concern; every AST that passed F0001 still
produces legal SQL.

# Examples — DFS to final fragment

| DFS input                       | Final fragment                                                                                  |
|---------------------------------|-------------------------------------------------------------------------------------------------|
| `name == "d'arc"`               | `unaccent_lower((tv.value_string)::text) = unaccent_lower('d''arc')`                            |
| `team == "L'#"équipe#""`        | `unaccent_lower((tv.value_string)::text) = unaccent_lower('L''"équipe"')`                       |
| `name LIKE "den%"`              | `unaccent_lower((tv.value_string)::text) LIKE unaccent_lower('den%')`                           |
| `code LIKE "50#%"`              | `unaccent_lower((tv.value_string)::text) LIKE unaccent_lower('50\%') ESCAPE '\'`                |
| `name LIKE "L'équipe de moi%"`  | `unaccent_lower((tv.value_string)::text) LIKE unaccent_lower('L''équipe de moi%')`              |
| `name LIKE "50 #% de l'élite%"` | `unaccent_lower((tv.value_string)::text) LIKE unaccent_lower('50 \% de l''élite%') ESCAPE '\'`  |
| `age >= 18`                     | `tv.value_integer >= 18`                                                                        |
| `is_open == FALSE`              | `tv.value_boolean = FALSE`                                                                      |
